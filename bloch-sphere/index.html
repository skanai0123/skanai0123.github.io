A

ON THE SURFACE

Pure states

For |r| = 1, the vector tip lies on the sphere. The computational basis states sit on the z-axis: |0⟩ = +Z and |1⟩ = −Z.

B

INSIDE THE SPHERE

Mixed states

For 0 ≤ |r| < 1, the tip lies inside the sphere. The center, ρ = I/2, is the maximally mixed state with no preferred direction.

C

PURITY

Vector length sets purity

Tr(ρ²) = (1 + |r|²) / 2

Shortening the vector lowers the purity continuously from 1 for pure states to 1/2 at the center.

D

VON NEUMANN ENTROPY

Entropy measures mixedness

S(ρ) = −Tr(ρ log₂ρ)

Equivalently, S = −Σᵢ λᵢ log₂λᵢ, where λ± = (1 ± |r|)/2. It ranges from 0 bit for a pure qubit to 1 bit for I/2.
