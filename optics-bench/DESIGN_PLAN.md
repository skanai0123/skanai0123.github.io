# Optics Bench — 設計ツールへの拡張計画

2026-08-28。前回の3素子試作を維持しつつ、配置した測定系を調整・保存・読み込みできる道具へ拡張する。静的HTML/CSS/JavaScriptのまま実装し、公開は別途依頼があるまで行わない。

## 1. 使う順序から画面を作る

1. 空のベンチ、または測定系プリセットを選ぶ。
2. 部品パレットからテーブルへドラッグ＆ドロップする。配置予定位置を半透明表示する。
3. 部品を直接移動し、選択中の部品の設定を右側で編集する。配置角度と偏光軸角度を区別する。
4. 波長ごとの光路、検出器に到達した相対パワー・光線数・偏光を確認する。
5. 設計JSONをダウンロードし、後で同じ単位・グリッド・素子設定で読み込む。図としてのSVG書き出しも用意する。

操作は22.5°刻みを標準にする。角度スライダーと回転操作は吸着を選べ、直接数値入力では任意角度も指定できる。Shift＋ホイール／拡大縮小ボタン、全体表示、背景ドラッグによるパンを提供する。元に戻す／やり直す・複製・削除を用意し、配置を試しやすくする。

キャンバスに固定の物理寸法を持たせず、負座標や離れた場所にも配置できるようにする。数値精度の保護として部品座標は±10億 mmまで。グリッド・目盛は現在の可視範囲だけを生成し、パン・ズームに追従する。光線は画面外の部品も追跡し、検出値を表示範囲に依存させない。「全体表示」は光線の長さではなく、全素子の外形・接続ケーブルを余白付きで収める。空の設計では初期表示へ戻す。読込後の全体表示には古い描画キャッシュではなく新しい配置を使う。

## 3. 単位と色

- 内部座標・JSONはmmに統一。cm／inch／mmの表示切替では素子の物理的位置・焦点距離・開口径を変えない。
- 単位を切り替えると標準グリッドもcm系／inch系に切り替える。グリッド間隔自体も指定可能。
- 可視域は波長に対応するsRGB近似色。UV・IRは不可視であることを文字と破線で示し、画面上の色を実際に目に見える色だと説明しない。
- 波長ラベルと光源一覧を併用し、色だけで波長を識別させない。低パワー光線の描画には視認性の下限を設けるが、定量値は検出欄で読む。

## 4. 計算の範囲

2次元光線追跡に、パワー・波長・Stokesベクトルを添える。理想偏光子・位相差板を通過させ、検出位置やクリックした光路区間で偏光成分を確認できる設計にする。光路の選択は素子の選択と独立し、同じ経路の再計算に追従。区間が消えたら過去の値を表示しない。近接光線は個別に切替え、パワーは光線1本分であることを明示する。偏光楕円・偏光度・Stokes値を示し、無偏光／円偏光の未定義角を区別する。選択状態は設計の履歴・保存から分離。ポアンカレ球の3次元ビュー、3次元的な光線座標変換、実コーティングのs/p位相差は次段階とする。

NPBSは従来のBSと同じ計算を保ち、PBSを別の部品として追加する。偏光0°はベンチ面外のs、90°は面内のp。PBSでは`(I−Q)/2`をp透過、`(I+Q)/2`をs反射へ分け、出力はそれぞれ直線偏光とする。理想的な有限分離面であり、実キューブの屈折・厚さ、有限消光比・損失・波長や入射角への依存は扱わない。

通常の光線は非干渉とし、干渉は第8節の独立した解析に限定する。回折・ガウシアン波動伝播・収差・蛍光量子収率・PSF・実ファイバーのモード重なり積分は計算しない。対物の高NAを入力できても薄レンズ近似の限界は消えない。ファイバーの表示値は幾何学的な光線の受光であり、厳密な結合効率と呼ばない。

## 5. 組み立てるプリセット

- 基本：レーザー → ミラー → レンズ。
- 4Fリレー：物体面、2枚のレンズ、像面の共役を確認する。
- ビームエキスパンダー：2枚の焦点距離と間隔で出射径を確認する。
- 偏光子とλ/4板：透過軸・速軸の変更と検出Stokesの変化を確認する。
- 2色分離：励起／蛍光に相当する2波長をダイクロイックで分ける。
- ファイバー結合：レンズの焦点位置に入口を置き、位置・NA・コア径を変更する。
- ファイバー伝送：2端面を双方向に接続し、入力集光 → 伝送 → 出射側で再コリメート。切断時の出射停止も確認する。接続線は模式図とし、実ファイバーのモード混合・伝送損失・偏光変化を再現したものと説明しない。
- 共焦点蛍光系：励起光 → ダイクロイック → 対物 → 試料位置、独立した蛍光点光源 → 対物 → ダイクロイック → 結像レンズ → ピンホール → 検出器。蛍光源は励起から自動生成したものではないことを明示する。焦点外の光源も比較できる構成にする。
- 50/50パワー分岐：NPBSの透過・反射出力を別々の検出器で読み、偏光状態に依存しない分岐比と透過率変更時のパワー収支を確認する。
- PBSの偏光分岐：45°線偏光をp透過・s反射へ半分ずつ分離。入力0°／90°で出力先が切り替わること、無偏光・円偏光でも分離後は直線偏光になることを確認する。

プリセットは配置名だけで完成扱いにしない。検出までの光路、パワー、焦点・開口条件をテストし、画面でも読み込んで調整する。

## 6. 保存と保護

形式名とschemaVersionを持つJSON。タイトル・表示単位・グリッド・吸着設定・全素子のパラメータを保存する。schemaVersion 2では端面IDの組`fiberLinks`も保存し、従来のschemaVersion 1は接続なしの設計へ移行する。読み込みではファイルサイズ、素子数、型、数値範囲、重複ID、未知の項目、接続先の存在・種類・一重接続を確認し、失敗時は現在の設計を維持する。文字列はHTMLとして解釈しない。部品単体のコピーは接続を含めず、schemaVersion 1の形式を維持する。従来13種のコピー互換は保持するが、新typeのPBSは旧アプリでは読み込めない。PBS追加で設計のschemaVersion 2は変えない。

プリセット読み込み・新規作成・JSON読込は元に戻せる。ブラウザーへの自動永続保存は今回の前提にしない。必要な設計をJSONとして保存することを画面に表示する。

## 7. 検証・完了条件

広域座標は、負座標・遠方の保存／コピー往復、全23プリセットの大きな平行移動、画面外の光学素子、自由光線の描画延長、可視範囲に依存しない偏光・パワー、グリッドの生成数、部品・ケーブルへの全体表示、空の設計・読込直後・狭い画面で検証する。パン・ズームで光路確認点が動かず、全体表示がUndo／Redoを消費しないことも確認する。

光路プローブは、PBS・偏光子・λ/4板の前後、重なった異波長・逆方向光線、微小クリックとパンの区別、ズーム時の許容距離、設定変更・消失・再出現、キーボードからの全区間アクセス、Undo／Redo保護、SVG出力からのマーカー除去を既存の編集・光学テストで検証する。実画面でもクリック、区間切替、通常幅／狭幅の偏光楕円を確認する。

反射・集光の既存回帰、Malus則、λ/4板の強度保存、NPBSの偏光非依存性、PBSのs/p分離・出力Stokes・配置回転・表裏・連続分岐・パワー保存、波長分離、アイリス遮断、ファイバー受光・双方向伝送・両端のNAとコア径・循環の打切り、プリセットの検出経路を自動テストする。JSON往復・旧版移行・不正接続・単位換算、接続のUndo／Redo、端面削除・単一部品コピーとの整合も検証する。

PCと狭い画面でパレット配置・配置後移動・角度吸着・ズーム・パン・元に戻す・プリセット・保存／読込を確認する。実施していない検証を完了扱いにしない。履歴と生成一覧を更新し、採番を確認する。既存の他ページとその作業中変更を保持する。

## 8. v0.7.0：実験プリセットと理想干渉解析

量子消しゴムは偏光を経路ラベルにするMZIの光学アナログとして実装する。単なる配置図にせず、実際の検出光路のJones振幅と光路位相から干渉を算出する。干渉Pのパネル・位相走査曲線・偏光素子のON/OFFを設け、通常の光線図と幾何Pには干渉が反映されないことを明示する。もつれ光子・同時計数・遅延選択・回折像を再現したとは扱わない。

- 追加部品はλ/2板と位相シフター。位相は1回通過ごとの0〜360°、角度吸着とは独立。保存形式v2・コピーv1は維持し、旧データの省略位相は0とする。
- 光線数1・ビーム径0のレーザーを理想モードの主光線とする。位置と方向の合う経路だけ合成する。別光源や無偏光入力の2基底は強度加算。未対応素子・重複面・追跡打切り・1 km超の光路では解析を停止する。
- 量子消しゴム、MZI、Michelson、三枚の偏光子、Malus則、λ/2＋PBS、円偏光分析、8段の偏光子、ガリレオ式拡大、2色合波、アイリス切り出し、波長板の波長比較を加え、全22プリセットにする。各々に変更する部品と期待値を記載する。
- 検証はJones/Stokes符号整合、干渉出力の強度保存、経路ラベルによる消失と射影による復元、相補射影の和が平坦、往復位相、ミラー位置変更、遮断・光軸ずれ、独立光源、通常光線への非干渉維持、保存・コピー・Undo、入力エラー、各プリセットの数値と通常幅／狭幅の実画面を対象にする。

- センサー幅・16〜1024の計算画素数・表示ゲイン・自動明るさを調整できるようにする。受光光線の位置・波長・Pから1列の画像とP/画素グラフを生成し、選択カメラの像を独立した欄で更新する。他の部品を編集中も表示を続ける。無受光・OFF・削除で古い像を残さない。

## 13. v0.11.0：波長フィルター・ND

- 19番目の部品`filter`をパレットから配置できるようにする。LP／SP／BP／NDを同じ部品で切替え、境界波長・帯域上下限・帯域内透過率・ODのうち必要な設定だけを表示する。配置の回転・ドラッグ・コピー・履歴に統合する。
- 波長はnm、Tはパワー比、NDは`10^(-OD)`。有限な薄い面で透過する光を減衰させ、遮断分は吸収として集計する。透過光の正規化Stokesは保つ。実測スペクトル・反射光・角度依存性・追加位相は対象外。干渉解析では位相なしの`√T`を掛ける。

## 33. v0.21.1：カメラ像のX/Y物理表示倍率を固定

## 37. v0.23.0：Cloudflareによる短縮共有リンク

- 既存のschemaVersion 2と`#ob1=`圧縮形式を維持し、圧縮済みハッシュだけを専用Cloudflare WorkerへPOSTする。Workers KVには圧縮payloadだけを保存し、固定の公開Optics Benchへ戻る短いURLを発行する。任意の転送先、Googleログイン、秘密鍵を画面側へ持たせない。
- SHA-256由来の決定的な12文字IDを使用し、同じ設計は同じURLへ集約する。異なるデータとの衝突時は16、20、32、43文字へ伸ばす。CORS、正規base64url gzip、入力長を検証し、KV内の値も取り出し時に再検証する。リンクは明示的に削除するまで期限なしとする。
- UIは短縮URLを優先し、接続失敗、回数制限、不正応答では公開ページと`#ob1=`を連結した長いURLへ切り替える。短縮サービス以外のorigin、query、hash、不正なIDは受け入れない。設計を知る人は内容を読めるため、暗号化・アクセス権管理・共同編集ではないことを明示する。
- Worker単体でCORS、入力検証、KV書込み、再利用、衝突、固定公開先への302を検証する。画面側は短縮リクエストの内容、応答URL検証、成功表示、長いURLへの切替、既存の保存・復元・Undoと非同期編集保護を回帰テストする。
