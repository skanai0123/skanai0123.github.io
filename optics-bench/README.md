# Optics Bench

光学部品をパレットからドラッグして配置し、光路・波長・開口・偏光を試す2次元の設計ツール。
静的HTML/CSS/JavaScriptで動作し、計算用の外部ライブラリやサーバーは不要。実機の光学性能・安全性を保証する解析ソフトではない。

## 操作仕様

- **光路の確認**：光の線をクリックすると、その区間の波長・相対P（サンプル光線1本分）・偏光楕円・偏光度・ψ／χ・Q/I、U/I、V/Iを表示する。選択区間の点線、確認位置の丸印、進行方向の矢印で場所を示す。選択中の部品はそのまま編集できる。近接・交差・往復する光線は「この位置付近の光線」で個別に切替え、別の波長や光線を合算しない。「光路を調べる」と前／次のボタンからも全区間へアクセスできる。空白クリック・閉じるボタン・Escで解除（文字入力中のEscは入力欄を優先）。
- **確認状態の更新**：設定変更時は同じサンプル・同じ通過経路の区間を追跡し、確認点を区間内の同じ割合の位置へ移す（進行先に素子がない光線では、最後の面からの距離を保持する）。遮断・無効化・光線本数変更などで選択区間が消えたら、以前の数値とマーカーを隠して未検出を表示する。光路選択だけでは設計を変更せず、Undo履歴やRedoを消費しない。新規・読み込み・プリセット・部品削除・Undo／Redoで選択を解除し、JSONやSVG出力には確認状態を含めない。光線のクリック許容距離は表示6px、ドラッグは4px以上で開始するため、グリッド・ズームに関わらず選べる。
- **選択・移動**：部品クリックで1個、Shift＋クリックで追加／解除。空白ドラッグの矩形内に中心が入る部品を複数選択し、Shift＋範囲選択では現在の選択へ追加する。「すべて選択」（Ctrl+A）と「選択解除」、Escも使用可能。選択中のどれかをドラッグすると相対位置を保って一括移動する。Shiftを押して掴むと、最初の移動量が大きいXまたはY方向へ固定し、途中でShiftを離しても維持する。グリッド吸着は掴んだ主選択へ1回だけ適用し、他の部品を個別に丸めない。座標上限でも共通変位を制限して配置を崩さない。ドラッグ中のEscで取消。
- **キャンバス移動**：選択ツールでは空白ドラッグを範囲選択に使う。「手」ツールまたはSpace＋空白ドラッグでパンする。Ctrl／Command＋背景ドラッグも従来互換でパンする。Shift＋ホイールまたは＋／−でズームする。
- **ドラッグで複製**：Ctrl（MacはCommand）を押しながら選択部品を掴み、配置先へドラッグする。複数選択中は全体の間隔・設定・選択内のファイバー接続を保持したプレビューを出し、新しいID群で配置する。開始後にCtrlを離しても複製のまま。Ctrl＋Shiftで掴むと複製先もX／Yへ固定。クリックだけでは複製せず、外側へドロップ・Esc・Ctrl+Z・ポインター操作の中断で取り消す。成功した複製は1回のUndo／Redoで戻せる。クリップボードの内容は変更しない。
- **ファイバー接続**：端面を2つ配置し、1つを選んで「接続先のファイバー」から相手を指定する。端面ごとに1本、最大40組の双方向接続。紫のケーブルが移動・回転に追従する。「相手を選択」で接続先を編集し、「切断」で解除する。接続・切断・再接続・削除はUndo対象。単一部品のコピーでは接続を持ち出さないが、接続された両端を複数選択して複製／コピーすると、その選択内の接続も新しいIDで複製する。選択外の相手は持ち出さず、既存の接続を奪わない。
- **角度**：スライダーと回転操作は22.5°刻みの吸着を切り替えられる。数値欄では任意角度を指定する。部品の面角度と、偏光子・λ/4・λ/2板の偏光軸角度は別の設定。位相φは吸着の対象外。R／Shift+Rで回転、Deleteで削除。
- **波長**：レーザー・点光源の波長を数値入力または選択ボタンで変更する。450 nmもワンクリックで設定でき、光線・色見本・光源一覧に反映する。波長色は表示用のRGB近似。
- **カメラ像**：カメラを置くとベンチの下にセンサー像と画素パワーのグラフを表示する。複数台は選択欄で切替え、レンズなど別の部品を編集中も現在のカメラ像を更新する。位置・向き・センサー幅・計算画素数・表示ゲイン・明るさ自動を調整可能。無受光やOFFでは黒くなる。計算するのは2D断面の1列分で、帯の縦方向は表示用の引き伸ばし。像を単独のSVGとして保存できる。
- **表示範囲**：Shift＋ホイールまたは＋／−でズーム、「手」またはSpace＋背景ドラッグでパン。配置の寸法は変わらない。
- **単位・グリッド**：cm／mm／inを切り替え、グリッド間隔と位置吸着を設定する。内部の長さは常にmm。単位切替で座標・焦点距離・開口径を拡大縮小しない。既定グリッドはcm・mm表示で10 mm、in表示で25.4 mm。
- **新規部品の既定寸法**：レーザーのビーム直径5 mm（0.5 cm）、平面ミラーの有効径25 mm（2.5 cm）、ダイクロイックとNPBS／PBSの分離面長36 mm（3.6 cm）。プリズム記号の36 mmは対角長なので外形は約25.5 mm角。設定欄から変更でき、保存済みの明示値は維持する。
- **履歴**：Ctrl+Zで元に戻す、Ctrl+Y／Ctrl+Shift+Zでやり直す。スライダーにフォーカスがある場合も使用可能。ドラッグ中のCtrl+Zは進行中の操作だけを取り消す。新規作成・プリセット・読み込みによる配置の変更も履歴の対象。
- **コピー・切り取り・貼り付け**：複数選択を含めてCtrl+C／X／VとCtrl+Dを使用できる。全パラメーター・名前・有効状態・相対位置、選択内のファイバー接続を保持し、別の設計やタブにも貼り付け可能。単一部品は従来の`component v1`、複数は`selection v1`の検証済みテキスト形式。元の中心群が空いていればmm座標を維持し、重なる場合は全体を同じ量だけ近くへずらす。新しいIDを付け、一括操作は1回のUndoで戻せる。コピーが失敗した場合は元を削除しない。
- **入力欄とショートカット**：文字・数値の入力欄、選択欄、編集可能な文章では通常の編集を優先し、部品の削除・貼り付けを行わない。説明文を選択中のコピーも通常どおり。MacではCtrlの代わりにCommandを使用できる。
- **保存・共有**：設計は「共有リンクをコピー」でURLに圧縮して保存し、開いた相手がそのまま復元できる。JSON保存・読み込みも引き続き使用可能。図として使う場合はSVG保存。SVGは再読込用の設計データではない。自動保存はしないため、必要な配置は共有リンクかJSONで残す。

固定サイズのテーブルを持たない無限キャンバス。原点は(0,0)、右が＋X、下が＋Yで、負の座標にも配置できる。最大80部品。数値精度を保護するため部品中心の座標は±10億 mm（±1000 km）までとし、非有限値や上限外の入力は拒否する。これは数値上の保護で、旧1000×600 mmの物理的な枠は設けない。

**全体表示**は有効・無効を含む全素子の外形と、接続ケーブルのベジェ制御点を含む範囲へ合わせる。余白を付け、現在の表示領域の縦横比を維持し、部品ゼロでは初期表示へ戻す。光線の描画終端は全体表示の対象にしない。プリセット・新規・JSON読込時も新しい配置の範囲で表示する。パン・ズーム・全体表示だけでは設計やUndo／Redoの履歴を変更しない。

グリッド・目盛・クリップ領域は画面の可視範囲へ追従し、グリッドを原点から全列挙しない。表示を間引いても位置吸着の間隔は保存値のまま。光線追跡は画面外も含む全素子を対象とし、進行先に素子がないときだけ部品範囲と表示範囲の外縁を描画終端にする。パン・ズームで検出値や偏光は変わらない。終端のない光線の確認点は最後の面からの距離を保持するため、描画距離が伸びても位置がずれない。SVGは現在見えている範囲を出力する。

設計JSONは引き続きschemaVersion 2、単一部品コピーはv1。以前の設計・コピーを読み込める。旧アプリは旧テーブル外の座標を許容しないため、新しい広域配置を読み込むにはこの版以降を使う。`WIDTH`／`HEIGHT`は初期表示と旧デモAPI用の定数で、現行`simulate`の物理境界ではない。
配置角度は時計回りで、光源は発射方向、ミラーは面の法線、レンズは光軸を表す。ファイバーとカメラの角度は受け入れる光線の進行方向。
設計方針と今回の対象範囲は[設計・検証計画](DESIGN_PLAN.md)を参照。

部品の転送はブラウザーの標準`copy`／`cut`／`paste`イベントを使う。単一部品は`Optics Bench component v1`、複数は`Optics Bench selection v1`の見出し付きJSONを`text/plain`へ入れ、受信時に形式・256 KiB制限・全パラメーター・内部接続を検証する。WindowsのCRLFにも対応。入力が不正、最大80部品に到達、またはグループを配置できる空き位置がない場合は現在の設計・履歴を変更しない。Clipboard APIの別途の読み取り許可は要求しない。[Clipboard API and events仕様](https://www.w3.org/TR/clipboard-apis/)

## 配置できる19種類

| 部品 | 主な設定・働き |
| --- | --- |
| レーザー | 中心波長・波長幅（全幅）・波長サンプル数、全帯域の相対パワー、光線束の直径・空間本数、直線／左右円／無偏光、直線偏光角 |
| 点光源 | 中心波長・波長幅（全幅）・波長サンプル数、全帯域の相対パワー、放射方向・扇形の全角・空間本数、偏光状態 |
| ミラー | 面の法線角度と有限な反射面の長さ。理想平面反射 |
| 凹面ミラー | 頂点位置・法線角度・有効径・正のf／R（R=2fで連動）。球面で反射集光、裏面は吸収 |
| レンズ | 正／負の焦点距離、光軸角度、有効径。近軸の薄レンズ |
| アイリス | 外径と開口径。開口0で完全閉鎖 |
| フィルター | LP／SP／BP／NDを切替。境界波長・透過帯域・帯域内透過率・光学濃度ODを設定。透過しない光は吸収として集計 |
| 偏光子 | 面角度と透過軸角度。理想線偏光子 |

| λ/2板 | 面角度、速軸角度、設計波長。設計波長で180°の位相差 |
| 位相シフター | 1回通過ごとの共通位相φ（0〜360°）。配置すると独立した干渉解析パネルが現れる |
| ダイクロイックミラー | カットオフ波長、Longpass／Shortpass、面角度 |
| 対物レンズ | 薄レンズの焦点距離・有効径に、空気中のNAによる制限を追加 |
| ファイバー | コア径、NA、受入方向、接続先。未接続なら受光終端、接続すると相手の端面へ光を転送 |
| ビームブロッカー | 有限な面に当たった光線を吸収 |
| 無偏光BS（NPBS） | 偏光によらず透過率Tで分岐。反射率は1−T。各出力の偏光状態を保持 |

全種類に位置・名前・有効／無効の設定がある。有効径／外径は2次元の横幅（凹面ミラーでは円弧の弦長）であり、3次元の円形開口を積分した値ではない。

**共焦点の比較**：対物f=50 mm、結像レンズf=75 mm、試料と共役な像面に直径1 mmのピンホールを置く。
励起レーザーと焦点内の点光源を無効にし、15 mmデフォーカスした「比較用の焦点外光源」を有効にすると、17本中3本だけが通り、検出パワーは約0.052941になる。開口を12 mmに広げると17本・0.3へ戻る。
既定の焦点内光源では、ピンホールの50 mm後方にある検出器での光線幅は約11.755 mmになる。これは再び広がった光線束の幅であり、ピンホール面のスポット径ではない。
これらの本数・パワーは離散的な幾何光学の確認値で、実機の遮光率や分解能ではない。

## 圧縮URLでの共有

「共有リンクをコピー」はクリックした時点の設計をスナップショットとして保存する。部品のID・位置・全設定・名前・有効状態、設計名、単位、グリッド、位置／角度吸着、ファイバー接続を含む。読み込んだ配置は全体表示へ合わせる。カメラ像や干渉結果は再計算し、ズーム・選択状態・Undo履歴・ラベル表示のON/OFF・プリセットの説明文は共有しない。コピーだけでは設計やUndo／Redoを変更しない。

リンクを開くと自動復元し、同じタブ内の共有URLへの移動にも対応する。復元は1回のUndoで戻せる。編集後は古いURLの内容を自動更新せず、共有欄を無効化して新しいリンクを作るよう知らせる。圧縮・展開中の編集や新しいURLへの移動は世代番号で検知し、古い処理結果で現在の設計を上書きしない。不正な入力欄がある場合はリンクを作らない。

`share.js`は既存のschemaVersion 2のJSONをUTF-8→gzip→パディングなしbase64urlにして`#ob1=...`へ格納する。座標や設定の桁は丸めない。圧縮・復元はブラウザー内で完結し、外部ライブラリ・保存サーバー・Googleログインは使わない。[WHATWG Compression Standard](https://compression.spec.whatwg.org/)の`CompressionStream`／`DecompressionStream`を使用し、未対応の場合は案内を出す。コピーには[Clipboard API](https://www.w3.org/TR/clipboard-apis/)の書き込みを使用し、拒否・未対応時は選択可能なURL欄とCtrl+C／⌘Cの案内を出す。クリップボードの読み取りは行わない。

共有URLは通常は現在の公開ページを使い、既存の検索クエリ・古いハッシュは持ち出さない。`file:`・localhost・127.x.x.x・IPv6 loopbackからは`https://skanai0123.github.io/optics-bench/`を使う。ローカルで生成したリンクには、この機能を公開するまでは相手側で復元できない旨を表示する。共有機能にはv0.10.0以降が必要で、GitHubへのpushや公開を自動では行わない。

**リンクを知る人は設計を読める。暗号化・アクセス権管理・共同編集ではない。** Googleドキュメント等へリンクを貼るだけでも共有できるが、その場所の閲覧者には設計も共有される。URLは部品や名前に応じて長くなり、8,000文字超で貼り付け先の制限に注意を表示する。ハッシュ上限65,536文字・展開後256 KiB・80部品。途中欠損、CRC不一致、不正UTF-8、不正形式・型・数値・接続を拒否し、現在の設計を保持する。展開は小さい入力チャンクと出力上限で制限する。通常のページ内アンカーは読み込まない。

## JSON形式と入力検証

`state.js`が保存・読込・単位変換を担当する。接続情報を含めてschemaVersion 2で保存し、以前のschemaVersion 1も接続なしの設計として読み込む。UTF-8のJSONで、最小例は次のとおり。

```json
{
  "format": "optics-bench",
  "schemaVersion": 2,
  "title": "実験系 A",
  "unit": "cm",
  "gridStep": 10,
  "snap": true,
  "angleSnap": true,
  "elements": [
    { "id": 1, "type": "laser", "x": 150, "y": 300, "angle": 0, "wavelength": 532 }
  ],
  "fiberLinks": []
}
```

- `unit`は表示単位であり、保存する`x`・`y`・`gridStep`・焦点距離・径は常にmm。波長はnm、角度は度、パワーは任意単位。
- ファイル上限256 KiB、部品上限80個。IDは1〜1,000,000,000の整数で重複不可。未対応の形式・版・部品種別・項目は拒否する。
- `fiberLinks`は`[{"a":3,"b":4}]`のような最大40組の接続。実在する異なるファイバー端面のIDだけを許し、自己接続・多重接続・重複・欠落IDを拒否する。無効の端面との接続関係は保存できるが伝送は停止する。schemaVersion 2では省略時は空配列。schemaVersion 1にこの項目を混在させることはできない。
- 接続を扱う設計はv0.3.0以降、PBSを含む設計はv0.4.0以降を使う。PBSの追加ではschemaVersion 2を維持し、従来の`splitter`はNPBSとして同じ設定・計算で読み込む。旧アプリは未対応の版・部品種別を拒否する。
- 部品単体のクリップボード形式は接続を含めず、schemaVersion 1で出力する。従来13種類の部品コピーの旧版互換は維持するが、新しい`pbs`の読み込みには対応版が必要。
- `halfwave`と`phase`を含む設計にはv0.7.0以降が必要。`phase`値は0〜360°、省略時0。設計schemaVersion 2・単一部品v1は維持する。位相シフター以外の未使用の0位相は書き出さず、従来部品の保存項目を保つ。干渉機能は位相シフターの有無から判定するため、プリセット名がなくても読込後に再計算できる。走査対象の選択・グラフ自体は保存しない。
- `concave`（凹面ミラー）を含む設計にはv0.8.0以降が必要。`focal`をmmで保存し、曲率半径は常に`2*focal`から導出する。fとRを別々に保存しないので、コピー・Undo・単位切替でも値が矛盾しない。schemaVersion 2・部品コピーv1は維持する。
- `camera`を含む設計にはv0.9.0以降が必要。`aperture`がセンサー幅（mm）、`pixelCount`が計算画素数、`exposure`が表示ゲイン、`autoExposure`が自動明るさの真偽値。省略時は24 mm／256画素／1／true。設計schemaVersion 2・部品コピーv1は維持し、カメラ以外の部品では未使用の既定値を省いて従来の保存項目を保つ。受光サンプルと像は保存せず再計算する。
- `filter`を含む設計・共有リンクにはv0.11.0以降が必要。`filterMode`は`longpass`／`shortpass`／`bandpass`／`nd`、`cutoff`・`bandLow`・`bandHigh`はnm、`opticalDensity`はOD、`transmission`は帯域内のパワー比。既定値はBP、500〜560 nm、境界600 nm、OD 1、T=1。種別を変えても未使用の設定を保持する。設計schemaVersion 2・部品コピーv1を維持し、フィルター以外の未使用の既定値4項目を省く。ダイクロイックの`mode`とは別の項目で、従来の分岐特性を変更しない。
- 光源の`wavelength`は中心波長、`wavelengthWidth`は全幅（nm・省略時0）、`spectralSamples`は波長分割数（省略時17）。中心±幅/2が200〜2500 nmからはみ出す帯域は拒否し、切り詰めない。幅0・分割数17の既定値は書き出さず、旧単色データの項目を保つ。幅0でも利用者が変えた分割数は保持する。新項目を含むJSON・部品コピー・共有リンクの読込にはv0.12.0以降が必要で、schemaVersion 2／部品コピーv1／共有ハッシュ形式は維持する。
- 非有限値、数値文字列、不正な列挙値、範囲外値を拒否する。型と範囲を検証した新しい配置を返し、失敗時は現在の配置を変更しない。任意コードの実行・外部参照の読み込みは行わない。
- 設計名は160文字、部品名は100文字まで。HTML・制御文字・プロトタイプ汚染用のキーは拒否する。既知の任意項目の省略時だけ既定値を補う。
- 配置角度・偏光角・偏光軸角度は保存形式では0〜360°を受け付け、360°を0°に正規化する。追加位相φは走査の終端を表せるよう360°をそのまま保存する。表示のズーム・パンやUndo履歴は保存しない。

## 計算モデルと限界

### 光路・光量

`optics.js`はDOMから独立した計算モジュール。前方にある有限線分・凹面ミラーの円弧との最短交点を順に追跡する。
ミラーは`d′ = d − 2(d·n)n`、レンズは進行側の局所座標で`u′ = u − h/f`を用い、逆方向入射にも対応する。
局所的な入射・出射角が15°を超えると注意を表示するが、この閾値は精度保証ではない。薄レンズ・近軸近似の前提は[NewportのLens Fundamentals](https://www.newport.com/n/optics-fundamentals/)を参照。

レーザーは一様幅の平行光線束、点光源は指定した2次元扇形を等パワーで離散化する。点光源のパワーはその扇形全体の値で、4π放射の集光率ではない。
通常の光線表示は非干渉。回折・レンズの収差・厚いレンズ・Gaussianビーム・M²・回折による焦点径は未計算。凹面ミラーの球面収差は下記の円弧反射で生じる。干渉は下記の独立した理想モード解析に限る。4F中央面のアイリスも幾何学的な光線選別であり、回折像の空間周波数処理ではない。
素子の外側は素通りし、筐体やマウントは遮光しない。面の重なり・交差では処理順に依存し得る。

検出パワーは光線パワーの和で、集光だけでは増加しない。重心はパワー重み付き、広がりは検出面での最大・最小位置の差で、FWHMや1/e²径ではない。
最大4096本の放出光線（空間本数×波長数の合計）、12000線分、1経路40交点で打ち切り、上限到達を警告する。開口の透過率は追跡本数に依存する。

### 光源の波長帯域

レーザーと点光源は「中心波長」「波長幅 Δλ（全幅）」で設定する。中心532 nm・幅20 nmなら522〜542 nm。幅0は従来の単色光で、古い配置・プリセットの光量や光路キーは変わらない。帯域内のスペクトルパワー密度をnmあたり一定とする有限帯域の模式モデルで、GaussianのFWHMや実測線形状ではない。

幅が正なら帯域をN個の等幅区間に分け、`λᵢ = λ中心 + ((i+0.5)/N − 0.5) Δλ`、`i=0…N−1`でサンプルする。区間の端ではなく中央の波長で、各波長に入力P/Nを割り当てる。各波長で同じ空間サンプル・入力偏光を使い、各光線はP/(空間本数×N)。光源の総パワーは分割数によらず一定だが、フィルターの端や狭い帯域の透過率は分割数・サンプル位置で変わる。幅より細い構造の解析には十分ではなく、Nを増減して確認する必要がある。上限で省いたパワーも打切り損失として光量収支へ記録する。

フィルター・ダイクロイック・位相板の既存特性を各入射波長で評価し、ファイバーや検出器へ波長とStokesを引き継ぐ。カメラはその各受光サンプルを合計する。ベンチ上の同じ空間光線・通過経路・端点に重なる波長サンプルは、表示用RGBをパワーで重み付けした1本として描画する。実際の色度・分光感度ではない。光路プローブは混ぜる前の各波長を個別に選択できる。光源の色見本は帯域のグラデーション、数値ラベルは上下限を示す。

波長間も通常の光線・カメラ像も非干渉。線幅から時間コヒーレンスを推定したり、中心波長1本で干渉を代用したりしない。波長幅が正の有効レーザーは干渉解析を停止し、幅0への変更を案内する。レンズの色収差・実測スペクトル・蛍光スペクトルの自動生成は対象外。

### 凹面ミラー

球面の2D断面である有限円弧を追跡する。鏡の座標は頂点、配置角度は頂点の法線方向。0°では凹面が左を向き、180°では右を向く。fは正の近軸焦点距離、Rは曲率半径の**大きさ**で`R=2f`。両方とも入力でき、他方が連動する。例えば[Newportの球面凹面ミラー仕様](https://www.newport.com/p/05DC200ER.1)はf=100 mm、符号付き曲率半径−200 mmを示すが、本ツールは半径を正値で扱い、鏡の向きを配置角度で指定する。

局所軸をu、横方向をhとすると、円弧は`u = −R + sqrt(R²−h²)`、`|h| ≤ 有効径/2`。有効径は`2R`未満とする。交点ごとに曲率中心からの法線nを求め、`d′ = d − 2(d·n)n`で反射する。裏面からの光は吸収する。深い円弧への複数回反射にも追跡上限内で対応し、重なり判定と描画にも同じ円弧を使う。

選択時のFは頂点から開いた側へf、CはRの位置。これは鏡単体の軸上ガイドで、間にあるBS等による光路の折返しは反映しない。球面鏡は太い平行ビームを厳密に一点へ集めないので、周辺光線はFより鏡に近い位置で軸を横切る。放物面・非球面・3Dの非点収差・回折像・コーティングの損失や偏光位相は未計算。通常の光線のStokes状態は従来の理想ミラー同様に保持する。**凹面ミラーを含む系の干渉解析は未対応**。

### カメラ像

カメラは**レンズを内蔵しないセンサー面**。結像には外部のレンズや凹面ミラーを置く。配置角度0°は右向きの入射を受け、裏面に当たる光は吸収して警告する。センサー幅を外れた光線は当たらない。センサー幅や画素ピッチの一般的な意味は[Edmund Opticsの撮像系パラメーター解説](https://www.edmundoptics.com/knowledge-center/application-notes/imaging/6-fundamental-parameters-of-an-imaging-system/)を参照。

受光した光線ごとに横位置・波長・パワーを記録し、`camera.js`が等間隔の計算画素へ加算する。横位置の正方向はカメラの配置角度＋90°。各画素のPは非干渉の和、画素ピッチはセンサー幅／画素数。表示色は波長のRGB近似をパワーで重み付けして加算する。画素数を増やしても追跡光線は増えず、像は離散サンプリングに依存する。補間や平滑化で光のない画素を埋めない。

「明るさ自動」では現在の最大画素Pを基準にし、OFFでは1画素P=1を基準にする。表示ゲインはそのRGB表示だけを倍率調整し、検出P・物理的な露光時間を変更しない。色の表示上限を超えた画素数を知らせる。下のP/画素グラフは常に最大Pに合わせて縦軸を拡大縮小し、数値を併記する。UV／IRには識別用の疑似色と注意を表示する。無受光・OFFでは以前の像を残さず黒くし、追跡打切り時は不完全な像であることを表示する。

この計算は**1列の幾何光学像**であり、画像の縦方向は未計算。回折・PSF・3D物体の写真・空間干渉縞・Bayer配列・量子効率・センサーノイズ・校正された色応答は含まない。カメラを有効にした系は独立した干渉解析の対象外で、通常の光線とカメラ像は非干渉のまま計算する。SVGは表示の記録で、設計の再読込用データではない。

### 偏光・波長

光線ごとに`(I,Q,U,V)`を保持し、`I`は光線パワー、`V=I_R−I_L`とする。基準は光線に垂直な局所座標で、その第1軸はテーブル面外。配置角度とは独立した偏光軸を使う。
理想線偏光子と位相板をStokes/Mueller形式で計算する。λ/4板の位相差は`δ=(π/2)×設計波長/入射波長`、λ/2板は`δ=π×設計波長/入射波長`という一定複屈折の近似。
符号の例として、速軸0°のλ/4板では`+U→−V`となる。左右円偏光の呼称はこの局所座標と符号規約に従う。
基準・形式は[COMSOLのStokesパラメーター](https://doc.comsol.com/6.4/doc/com.comsol.help.roptics/roptics_ug_optics.6.65.html)と[Mueller行列の説明](https://doc.comsol.com/6.4/doc/com.comsol.help.roptics/roptics_ug_optics.6.72.html)を参照する。

光路プローブは、この基準のStokes値から偏光度 `sqrt(Q²+U²+V²)/I`、方位角 `ψ = atan2(U,Q)/2`（0～180°）、楕円率角 `χ = atan2(V,sqrt(Q²+U²))/2`（−45～45°）を算出する。楕円の短軸／長軸比は `|tan χ|`。断面図はsを横、pを上に取り、ベンチの配置角度とは別に示す。V>0を右、V<0を左とする既存の規約を維持する。部分偏光では偏光成分の楕円と全体の偏光度を別々に表示し、無偏光は一定の楕円なし・ψ/χ未定義、円偏光はψ未定義とする。強度分布・干渉を描くものではなく、各区間の値は終端素子に入る前の状態を表す。

ミラー・ダイクロイック・BSのコーティングに由来するFresnel位相差、実素子の分散・有限消光比・吸収は含まない。PBSによるs/p成分の分離は下記の理想投影で計算する。通常の検出表では分岐や異なる光源を非干渉のパワーとして加算する。
ダイクロイックは理想ステップ特性で、Longpassは`λ≥cutoff`、Shortpassは`λ≤cutoff`を透過する。境界波長はどちらも透過。遷移帯域・入射角依存性はない。
380〜780 nmの表示色は区分的なRGB近似で、範囲外は識別用の色。厳密な測色や校正された明るさではなく、紫外・赤外を肉眼で見える色として再現するものでもない。

### 波長フィルター・ND

パレットの「フィルター」を置き、種別をLP／SP／BP／NDから選ぶ。必要な設定だけを表示し、切替前の数値は保持する。帯域の逆転・範囲外の入力では直前の有効値を使う。波長は表示単位に関係なくnm、配置角度は面の法線。有限な幅の外を通る光はフィルターに作用されない。

LPは`λ ≥ cutoff`、SPは`λ ≤ cutoff`、BPは`bandLow ≤ λ ≤ bandHigh`で帯域内透過率Tを適用し、帯域外は0とする。境界は透過側に含む理想ステップで、実フィルターの50%波長やFWHMとは異なる。NDは波長に関係なく`T = 10^(-OD)`を適用する。OD 0／1／2で100／10／1%、重ねたときのODは加算になる。NDモードでは帯域内Tの値を使わない。[光学フィルターの種類と特性（Edmund Optics）](https://www.edmundoptics.com/knowledge-center/application-notes/optics/optical-filters)、[ODと透過率の定義（Edmund Optics）](https://www.edmundoptics.eu/f/reflective-neutral-density-nd-filters/11987)

透過方向を変えず、StokesのI/Q/U/Vを同じTで減衰させる。透過しない分は吸収として光量収支に加え、反射光は発生させない。これはシミュレーターの仮定で、実際のフィルターには反射型もある。入射角依存性・膜厚・遷移帯域・波長ごとの実測曲線・偏光依存性・分散位相・熱や損傷は未計算。干渉解析でも追加位相のない実振幅`√T`として扱う。光路のプローブ・検出器・カメラには、減衰後の光がそのまま届く。

### NPBSとPBS

パレットから2種類を別々に配置できる。NPBSには透過率Tの入力・スライダーがあり、PBSには分離する偏光の説明を表示する。配置角度は面の法線であり、入力レーザーの偏光角とは別の値。

パレットからの追加・配置プレビュー・既定値を使うプリセットは同じ標準サイズを使う。標準の**分離面の長さは36 mm**で、設定欄から変更できる。二つの三角プリズムを合わせた正方形の記号を描き、その中央の対角線が分離面に対応する。`aperture`はこの対角線の長さであり、外形の一辺ではないため、外形は約25.5 mm角になる。配置角45°では正方形の辺がグリッドに平行になる。NPBSは青、PBSは桃色とPの印で区別する。

**光学的な厚さは0**。プリズムの外形は表示・選択用で、外周での屈折・反射・遮光やガラスによる光路長を追加しない。透過・反射は同じ分離面上の点から始まり、従来の理想光学モデルを維持する。変更済みのサイズやJSONに保存された寸法は上書きしない。太い入力では一部がBSを素通りするため、必要に応じて分離面を広げる。「凹面ミラーで反射集光」は30〜90 mmビームの比較条件を保つため、プリセット固有の100 mm NPBSを使う。

**NPBS（無偏光BS）**は入力の偏光に依存せず、透過へ`T × (I,Q,U,V)`、反射へ`(1−T) × (I,Q,U,V)`を渡す理想モデル。規格化したStokes値を各出力で保持する。「無偏光」は入力を無偏光化する意味ではなく、偏光に依存しない分岐比を表す。従来のBSの数値挙動は変えない。[BSの種類の解説（Edmund Optics）](https://www.edmundoptics.com/knowledge-center/application-notes/optics/what-are-beamsplitters/)

**PBS（偏光BS）**はp成分を直進透過、s成分を反射する。2次元ベンチの偏光0°は面外のs方向で`Q>0`、90°は面内のp方向で`Q<0`。入力`(I,Q,U,V)`から、透過パワー`Pp=(I−Q)/2`、反射パワー`Ps=(I+Q)/2`を求め、出力をそれぞれ`(Pp,−Pp,0,0)`と`(Ps,+Ps,0,0)`にする。したがって線偏光角θでは透過率が`sin²θ`、反射率が`cos²θ`となり、無偏光・円偏光は直交する直線偏光へ半分ずつ分かれる。[s/pの基準（Edmund Optics）](https://www.edmundoptics.com/knowledge-center/application-notes/optics/introduction-to-polarization)、[p透過・s反射のPBS（Newport）](https://www.newport.com/f/broadband-polarizing-cube-beamsplitters)

PBSは有限長の理想分離面とし、表裏とも固定したs/p基準を使う。キューブの厚さ・屈折・光路長、有限消光比による漏れ、損失、入射角や波長による分岐特性の変化、通常の光線表示での枝間の位相と干渉は計算しない。別欄の干渉解析では下記の理想振幅を使う。実NPBSにもs/pの分岐差や位相差が残り得るため、上記の偏光保持はこのモデルの仮定であり、製品の厳密な特性ではない。[実NPBSのs/p特性（Newport）](https://www.newport.com/f/laser-line-non-polarizing-cube-beamsplitters)

### 干渉解析と量子消しゴム

位相シフターを配置すると`coherence.js`による解析パネルを表示する。φのスライダー（1°刻み、角度吸着とは独立）・任意の数値・0／90／180°ボタン、偏光素子を入れる／外すボタンを用意する。通常の部品編集と同じ設定が変わり、Undo／Redo・保存・コピーが可能。複数の位相シフターでは、走査対象を切替えられる。

`optics.js`が実際に通過した面・分岐側・検出位置と進行方向を記録する。各経路をJones振幅で計算し、空気中の伝播位相`2πL/λ`と各位相シフターを通るたびのφを足す。ミラーの共通反射振幅は−1、対称な損失なしNPBSは`t=√T, r=i√(1−T)`、PBSはp透過・s反射（反射にi）を仮定する。波長板は速軸と遅軸の射影で構成し、既存のStokesのV符号と一致させる。コーティングの実測位相ではない。

同じレーザーからの経路が、同じスクリーン位置（許容差10⁻⁵ mm）かつ同じ進行方向（単位ベクトル差10⁻⁷以下）に達したときだけ振幅を合成する。有限径のモード重なり積分や、傾いた光線の空間的な縞は計算しない。光軸がずれた経路は別モードとして強度を加算する。別レーザーも相互に非干渉。無偏光レーザーはs／pの2つの非干渉モードに分け、各モード内の光路間コヒーレンスを保つ。線幅・有限コヒーレンス長・時間平均は未計算。

対応する光源は**光線数1・ビーム径0・波長幅0のレーザー**。ビーム径0は実ビーム径がゼロという意味ではなく、1本の主光線で理想空間モードを表すための指定である。対応素子は平面ミラー・NPBS・PBS・偏光子・λ/4・λ/2・位相シフター・アイリス・フィルター・ブロッカー・スクリーン。幅のある光源、点光源・レンズ・凹面ミラー・対物・ファイバー・ダイクロイック・カメラが有効な場合、面が重なる場合、パワー閾値や追跡上限で打切りがある場合は解析を停止し、古いグラフ・数値を隠す。位相精度の保護として各検出光路は1 km以下に制限する。

干渉Pは検出器での複素振幅の合成結果。通常の光線の濃さ、個別光路プローブ、幾何検出表の強度・Stokes・幅、幾何光学のパワー収支は書き換えない。干渉による吸収パワーの再計算や全場の描画はしない。暗い出力でもベンチに幾何光線が残ることを画面で明記する。グラフはφを2°刻みで走査し、可視度Vはその最大・最小から計算する近似。無受光のVは未定義。

量子消しゴムプリセットは、**偏光で経路を区別し、検光子への射影で干渉を復元する光学アナログ**。単一光子でも同じ一次干渉の振幅式が、入力で規格化した検出確率に対応する。もつれ光子対、同時計数、遅延選択、二光子干渉、単一光子源の生成、検出統計は扱わず、「未来の選択が過去を変える」とは解釈しない。D₁の45°と135°の検光結果を足すと、φによらず0.5になる。

経路の偏光ラベルと射影の参考：[Schwindt, Kwiat & Englert (1999)](https://arxiv.org/abs/quant-ph/9908072)。レーザーによる古典光学アナログの参考：[Khandelwal et al., A cost-effective quantum eraser demonstration](https://arxiv.org/abs/2204.12728)。後者は二重スリット実験であり、このページのMZI配置をそのまま転載・再現したものではない。

### 共焦点・ファイバー

共焦点プリセットの650 nm光は、励起光から生成した蛍光ではなく**独立した点光源**。励起光量との関係、量子収率、寿命、3D PSF、走査画像、実機の分解能は計算しない。
ダイクロイックによる励起／蛍光の分離は[Nikonの蛍光顕微鏡解説](https://www.microscopyu.com/techniques/fluorescence/introduction-to-fluorescence-microscopy)、試料とピンホールの共役関係は[浜松ホトニクスの共焦点原理解説](https://www.hamamatsu.com/us/en/product/life-science-and-medical-systems/mems-confocal-unit/principle-of-confocal.html)に沿って模式配置した。

ファイバーはコア内への入射、前向きの進行方向、空気中の`sin(入射半角)≤NA`を満たした光線だけを受け入れる。
表示値は幾何学的な受光率であり、単一モード結合効率・モード重なり積分・伝送損失ではない。[NewportのFiber Optic Coupling](https://www.newport.com/n/fiber-optic-coupling)も光線による取り込みと単一モードのモード整合を区別している。

接続済みの端面は**理想的な幾何伝送**として扱う。入力軸に対する光線の横位置（絶対mm）と角度成分を、接続先の出射軸へ回転して移す。出射軸は接続先の配置角度＋180°。波長・パワー・Stokesは保持し、コア径に合わせた光束の拡大縮小は行わない。出射側のコア径・NAを超える光線はそこで遮断する。未接続の場合と、接続相手を無効にした場合は、従来の受光終端となる。ケーブルの曲線は表示だけであり、光路長・遅延・位相・曲げ損失には換算しない。

受光Pは各端面への入射のうち取り込めた量、出射Pは相手から転送されてその端面から出た量。接続中の受光は光を消費しないモニター値で、最終検出パワーに二重加算しない。循環する光路では同じ光が何度も通るため、端面の通過累計が光源パワーを超える場合がある。終端の収支は`sourcePower = escapedPower + absorbedPower + detectedPower + discardedPower`を維持し、循環は既存の40相互作用上限で止める。

これは実ファイバー内部のモード伝播モデルではない。モード混合・出射角の変化は[Thorlabsのマルチモードファイバー解説](https://www.thorlabs.com/newgrouppage9.cfm?objectgroup_ID=10638)、曲げ・応力による偏光変化は[Newportの偏光解説](https://www.newport.com/t/polarization-in-fiber-optics)を参照。単一モードの回折発散、モード混合、偏光保持性能、伝送損失・分散は再現しない。

参考資料は2026-08-28参照。本文・図版は転載していない。
