# Optics Bench

光学部品をパレットからドラッグして配置し、光路・波長・開口・偏光を試す2次元の設計ツール。
静的HTML/CSS/JavaScriptで動作し、計算用の外部ライブラリやサーバーは不要。実機の光学性能・安全性を保証する解析ソフトではない。

## 操作仕様

- **配置・移動**：パレットからグリッドへドラッグ＆ドロップして追加。配置済み部品もドラッグで動かす。ドラッグ中のEscで取消。クリック／Enterによる追加や、選択部品の矢印キー移動も用意する。
- **角度**：スライダーと回転操作は22.5°刻みの吸着を切り替えられる。数値欄では任意角度を指定する。部品の面角度と、偏光子・λ/4板の偏光軸角度は別の設定。R／Shift+Rで回転、Deleteで削除。
- **表示範囲**：Shift＋ホイールまたは＋／−でズーム、背景ドラッグでパン。配置の寸法は変わらない。
- **単位・グリッド**：cm／mm／inを切り替え、グリッド間隔と位置吸着を設定する。内部の長さは常にmm。単位切替で座標・焦点距離・開口径を拡大縮小しない。既定グリッドはcm・mm表示で10 mm、in表示で25.4 mm。
- **履歴**：Ctrl+Zで元に戻す、Ctrl+Shift+Zでやり直す。新規作成・プリセット・読み込みによる配置の変更も履歴の対象。
- **保存**：再編集する設計はJSON保存・読み込み、図として使う場合はSVG保存。SVGは再読込用の設計データではない。自動保存はしないため、必要な配置はJSONで残す。

テーブルは1000×600 mm、最大80部品。左上が原点、右が＋X、下が＋Y。部品中心の範囲はX=50〜950、Y=50〜550 mm。
配置角度は時計回りで、光源は発射方向、ミラーは面の法線、レンズは光軸を表す。ファイバーの角度は受け入れる光線の進行方向。
設計方針と今回の対象範囲は[設計・検証計画](DESIGN_PLAN.md)を参照。

## 配置できる13種類

| 部品 | 主な設定・働き |
| --- | --- |
| レーザー | 波長、相対パワー、光線束の直径、本数、直線／左右円／無偏光、直線偏光角 |
| 点光源 | 波長、相対パワー、放射方向・扇形の全角、本数、偏光状態 |
| ミラー | 面の法線角度と有限な反射面の長さ。理想平面反射 |
| レンズ | 正／負の焦点距離、光軸角度、有効径。近軸の薄レンズ |
| アイリス | 外径と開口径。開口0で完全閉鎖 |
| 偏光子 | 面角度と透過軸角度。理想線偏光子 |
| λ/4板 | 面角度、速軸角度、設計波長。設計波長で90°の位相差 |
| ダイクロイックミラー | カットオフ波長、Longpass／Shortpass、面角度 |
| 対物レンズ | 薄レンズの焦点距離・有効径に、空気中のNAによる制限を追加 |
| ファイバー | コア径、NA、受入方向。端面で受光し、以後の伝播は追跡しない |
| ビームブロッカー | 有限な面に当たった光線を吸収 |
| ビームスプリッター | 透過率Tで分岐。反射率は1−T |

全種類に位置・名前・有効／無効の設定がある。有効径／外径は2次元の線分長であり、3次元の円形開口を積分した値ではない。

## 8種類のプリセットと数値確認

以下は`optics.js`と`presets.js`を同じNodeテストで実行した結果。パワーは任意単位で、特記のない光源の入力は1。
全8配置について、有限な光線座標、有効な検出光路、追跡打切りなし、既定配置の警告なしを確認した。

| プリセット | 配置・確認結果 |
| --- | --- |
| ミラーとレンズ | 45°のミラーで折返し、f=125 mmで集光。9/9本が(550,75) mmで重なり、受光パワー1 |
| 4Fリレー | f₁=f₂=100 mm、レンズ間200 mm。光軸から−10 mmの物点が＋10 mmに結像し、倍率−1。像の重心(600,310) mm、17/17本を検出 |
| 2×ビームエキスパンダー | f₁=50 mm、f₂=100 mm、間隔150 mm。12 mmの平行光線束が24 mmになり、出射は平行 |
| 偏光子とλ/4板 | 0°直線偏光→速軸45°のλ/4板→90°検光子でパワー0.5。λ/4板を無効にすると0 |
| ダイクロイックによる2色分岐 | 600 nm Longpassで532 nmを反射、650 nmを透過。各ポートにパワー1。Shortpassに変更すると行き先が逆転 |
| ファイバーへの集光 | f=100 mm、コア径0.2 mm、NA=0.12で17/17本を受光。端面を横へ1 mm移動すると0本。NA低下やアイリス閉鎖でも減光 |
| 共焦点蛍光顕微鏡の光路 | 532 nm励起を対物で試料点へ集光。独立な650 nm点光源の17/17本がピンホールを通り、検出パワー0.3。励起光は検出器へ入らずブロッカーに到達 |
| 50/50パワー分岐 | 2つの出力が0.5ずつ。Tを0.25にすると0.25／0.75となり、合計1を維持 |

**共焦点の比較**：対物f=50 mm、結像レンズf=75 mm、試料と共役な像面に直径1 mmのピンホールを置く。
励起レーザーと焦点内の点光源を無効にし、15 mmデフォーカスした「比較用の焦点外光源」を有効にすると、17本中3本だけが通り、検出パワーは約0.052941になる。開口を12 mmに広げると17本・0.3へ戻る。
既定の焦点内光源では、ピンホールの50 mm後方にある検出器での光線幅は約11.755 mmになる。これは再び広がった光線束の幅であり、ピンホール面のスポット径ではない。
これらの本数・パワーは離散的な幾何光学の確認値で、実機の遮光率や分解能ではない。

## JSON形式と入力検証

`state.js`が保存・読込・単位変換を担当する。UTF-8のJSONで、最小例は次のとおり。

```json
{
  "format": "optics-bench",
  "schemaVersion": 1,
  "title": "実験系 A",
  "unit": "cm",
  "gridStep": 10,
  "snap": true,
  "angleSnap": true,
  "elements": [
    { "id": 1, "type": "laser", "x": 150, "y": 300, "angle": 0, "wavelength": 532 }
  ]
}
```

- `unit`は表示単位であり、保存する`x`・`y`・`gridStep`・焦点距離・径は常にmm。波長はnm、角度は度、パワーは任意単位。
- ファイル上限256 KiB、部品上限80個。IDは1〜1,000,000,000の整数で重複不可。未対応の形式・版・部品種別・項目は拒否する。
- 非有限値、数値文字列、不正な列挙値、範囲外値を拒否する。型と範囲を検証した新しい配置を返し、失敗時は現在の配置を変更しない。任意コードの実行・外部参照の読み込みは行わない。
- 設計名は160文字、部品名は100文字まで。HTML・制御文字・プロトタイプ汚染用のキーは拒否する。既知の任意項目の省略時だけ既定値を補う。
- 角度は保存形式では0〜360°を受け付け、360°を0°に正規化する。表示のズーム・パンやUndo履歴は保存しない。

主な許容範囲は次のとおり。単位切替によって上限・下限の物理量は変わらない。

| パラメーター | 範囲 |
| --- | --- |
| グリッド間隔 | 1〜254 mm |
| 波長・設計波長・カットオフ | 200〜2500 nm |
| 光源パワー・追跡本数 | 0〜100、1〜61本の整数 |
| 有効径／外径・レーザー光線束径 | 2〜300 mm、0〜200 mm |
| 焦点距離 | −1000〜−1 mmまたは1〜1000 mm |
| 点光源の扇形全角 | 1〜360° |
| アイリス開口・ファイバーコア径 | 0〜300 mm、0.01〜200 mm。各部品の外径以下 |
| NA・ビームスプリッター透過率 | 0.01〜1、0〜1 |

## 計算モデルと限界

### 光路・光量

`optics.js`はDOMから独立した計算モジュール。前方にある有限線分との最短交点を順に追跡する。
ミラーは`d′ = d − 2(d·n)n`、レンズは進行側の局所座標で`u′ = u − h/f`を用い、逆方向入射にも対応する。
局所的な入射・出射角が15°を超えると注意を表示するが、この閾値は精度保証ではない。薄レンズ・近軸近似の前提は[NewportのLens Fundamentals](https://www.newport.com/n/optics-fundamentals/)を参照。

レーザーは一様幅の平行光線束、点光源は指定した2次元扇形を等パワーで離散化する。点光源のパワーはその扇形全体の値で、4π放射の集光率ではない。
回折・干渉・収差・厚いレンズ・Gaussianビーム・M²・焦点の有限径は未計算。4F中央面のアイリスも幾何学的な光線選別であり、回折像の空間周波数処理ではない。
素子の外側は素通りし、筐体やマウントは遮光しない。面の重なり・交差では処理順に依存し得る。

検出パワーは光線パワーの和で、集光だけでは増加しない。重心はパワー重み付き、広がりは検出面での最大・最小位置の差で、FWHMや1/e²径ではない。
最大4096本の放出光線、12000線分、1経路40交点で打ち切り、上限到達を警告する。開口の透過率は追跡本数に依存する。

### 偏光・波長

光線ごとに`(I,Q,U,V)`を保持し、`I`は光線パワー、`V=I_R−I_L`とする。基準は光線に垂直な局所座標で、その第1軸はテーブル面外。配置角度とは独立した偏光軸を使う。
理想線偏光子と位相板をStokes/Mueller形式で計算する。λ/4板の位相差は`δ=(π/2)×設計波長/入射波長`という一定複屈折の近似。
符号の例として、速軸0°のλ/4板では`+U→−V`となる。左右円偏光の呼称はこの局所座標と符号規約に従う。
基準・形式は[COMSOLのStokesパラメーター](https://doc.comsol.com/6.4/doc/com.comsol.help.roptics/roptics_ug_optics.6.65.html)と[Mueller行列の説明](https://doc.comsol.com/6.4/doc/com.comsol.help.roptics/roptics_ug_optics.6.72.html)を参照する。

ミラー・ダイクロイック・ビームスプリッターの反射に伴うFresnel位相差・偏光変換、実素子の分散・消光比・吸収は含まない。分岐や異なる光源は非干渉のパワーとして加算する。
ダイクロイックは理想ステップ特性で、Longpassは`λ≥cutoff`、Shortpassは`λ≤cutoff`を透過する。境界波長はどちらも透過。遷移帯域・入射角依存性はない。
380〜780 nmの表示色は区分的なRGB近似で、範囲外は識別用の色。厳密な測色や校正された明るさではなく、紫外・赤外を肉眼で見える色として再現するものでもない。

### 共焦点・ファイバー

共焦点プリセットの650 nm光は、励起光から生成した蛍光ではなく**独立した点光源**。励起光量との関係、量子収率、寿命、3D PSF、走査画像、実機の分解能は計算しない。
ダイクロイックによる励起／蛍光の分離は[Nikonの蛍光顕微鏡解説](https://www.microscopyu.com/techniques/fluorescence/introduction-to-fluorescence-microscopy)、試料とピンホールの共役関係は[浜松ホトニクスの共焦点原理解説](https://www.hamamatsu.com/us/en/product/life-science-and-medical-systems/mems-confocal-unit/principle-of-confocal.html)に沿って模式配置した。

ファイバーはコア内への入射、前向きの進行方向、空気中の`sin(入射半角)≤NA`を満たした光線だけを受け入れる。
表示値は幾何学的な受光率であり、単一モード結合効率・モード重なり積分・伝送損失ではない。[NewportのFiber Optic Coupling](https://www.newport.com/n/fiber-optic-coupling)も光線による取り込みと単一モードのモード整合を区別している。

参考資料は2026-08-28参照。本文・図版は転載していない。
