# Random Walk Lab

現在版 **v1.1.0** / 内容更新日 **2026-09-14**。

1〜100次元、7種類の歩行モデルを同じ距離指標で比較し、原点からの距離がステップ数の何乗で増えるかを調べる静的ページ。全座標を使った3D投影、平行座標、座標と時間のヒートマップにより、高次元の位置も観察する。HTML / CSS / JavaScriptのみで動作し、計算はブラウザー内で実行する。

## 計算モデルと距離の意味

全試行を原点から開始する。粒子間の相互作用はなく、各粒子の移動規則は選んだモデルで決まる。画面の尺度Lは1に固定するが、Lの意味は「1軸ずつ進む格子歩行の歩幅」であり、全モデルの毎ステップの全長を一律に1にそろえているわけではない。

時間tは**経過したステップ数**であり、秒ではない。画面では **L = 1** に固定し、距離を歩幅の単位で表示する。N次元位置をx(t)、原点からのユークリッド距離をr(t)として、

```text
r(t) = sqrt(x₁(t)² + … + xₙ(t)²)
MSD(t) = mean(r(t)²)
RMS(t) = sqrt(mean(r(t)²))
平均距離(t) = mean(r(t))
```

`mean`は同じ時刻における全試行の算術平均。RMSと平均距離は異なる量であり、平均距離はRMS以下になる。rは原点からの距離であり、移動経路に沿った累積の道のりではない。偏りのあるモデルでも、MSDから平均位置の移動を差し引かない。

### 7種類のモデル

| モデル / 設定キー | 各ステップの規則 | MSDの理論値、または目安 |
| --- | --- | --- |
| 通常：1軸ずつ / `lattice` | ±e₁…±eₙから等確率で1方向を選び、L進む | L²t |
| 各軸に独立なノイズ / `independent` | 全N軸で、それぞれ独立に+Lか−Lへ進む | NL²t |
| ガウス歩行 / `gaussian` | 全N軸で、平均0・分散L²/Nの独立な正規乱数を加える | L²t |
| 偏りのある歩行 / `biased` | 確率bで+x₁へL、それ以外は通常の等確率歩行 | L²[(1−b²)t + b²t²] |
| 方向が続く歩行 / `persistent` | 最初は等確率の方向。その後は確率pで前方向を継続し、それ以外は全2N方向から等確率で再抽選 | L²[t + 2Σₖ₌₁ᵗ⁻¹(t−k)pᵏ] |
| 箱の中の歩行 / `confined` | 通常の移動を提案し、いずれかの軸で箱[−RL,RL]を出る提案は棄却、その時刻は同じ場所に留まる | 長時間のMSDはNL²R(R+1)/3に収束 |
| 自己回避成長 / `selfAvoiding` | 自分が未訪問の隣接格子点から等確率で1点を選ぶ。候補がなければ以後停止 | 決まった理論べき指数は表示しない |

`independent`の1歩の全長は√N Lであり、軸ごとのノイズ強度を固定して次元を増やす例。`gaussian`の1歩の全長は変動するが、二乗長の期待値はL²。単純な次元比較では、**次元数だけでなく1ステップの正規化**にも注目する。

### 通常拡散と指数

`lattice`では独立なステップの平均変位は0、各ステップの二乗長はL²なので、交差項の期待値が消え、

```text
E[x(t)] = 0
E[r(t)²] = t L²
sqrt(E[r(t)²]) = L sqrt(t)
```

が成り立つ。したがって、**通常拡散ではRMSの理論指数は1/2、MSDの理論指数は1**。`lattice`の総距離の理論RMSに次元数Nの係数は付かず、各座標成分の二乗変位の期待値はtL²/N。`independent`では係数が√N倍になるが、RMSの指数は同じ1/2である。`gaussian`もRMSの指数は1/2になる。

`biased`では平均位置がE[x(t)] = bLt e₁となる。0 < b < 1なら初期の拡散項と後期のドリフト項の間でRMSの見かけの指数が1/2から1へ変化する。b = 0は通常拡散、b = 1は直進である。

`persistent`の方向相関はpᵏ。再抽選では直前と同じ方向も選べるため、「実際に同じ方向になる確率」はpそのものではない。pが1に近い場合、短時間には直進的な指数1が見え、十分な長時間では指数1/2に近づく。0 ≤ p < 1で長時間のMSDの係数はL²(1+p)/(1−p)、p = 1ではMSD = L²t²である。

`confined`では境界に達する前は拡散し、十分な時間がたつと有限の箱へ分布が広がってRMSが飽和する。飽和後のべき指数の目安は0。箱の定常分布は格子点上で一様なので、各軸の二乗位置平均がL²R(R+1)/3となる。上表は飽和値であり、途中の時間発展を一本のべき則で厳密に記述する式ではない。

### 自己回避成長と平衡自己回避歩行の区別

`selfAvoiding`は**kinetic growth walk**。自分の過去の訪問点だけを避け、他の粒子の軌跡は避けない。行き止まりになった粒子は停止位置に残し、統計の分母にも含め続ける。したがって停止が増えれば距離の曲線も飽和し得る。ここでの時刻tは移動を試みる刻みであり、停止後は成功した歩数とは異なる。

全ての同じ長さの自己回避経路を等確率で平均する**平衡自己回避歩行**をサンプリングしているわけではない。成長過程では選択肢の数が経路ごとに異なり、経路の確率が等しくならない。平衡自己回避歩行の2次元ν = 3/4という理論予測、3次元ν ≈ 0.588という推定値を、この成長モデルの正解線として用いない。平衡系を再現するには別のサンプリングや重み付けが必要になる。

理論曲線は無限の試行についての期待値を示す。画面の有限な試行数から求めたRMSやフィット指数は乱数によって変動し、理論線との一致は保証されない。平均位置ベクトルが期待値として0であることも、各試行の原点からの距離が0になることを意味しない。

## 設定と計算量

| 設定 | 既定値 | 範囲 |
| --- | ---: | --- |
| モデル | `lattice` | 上記7種類 |
| 次元N | 2 | 整数1〜100。自己回避成長は1〜10 |
| 試行数 | 512 | 画面では128・512・2,048・4,096から選択 |
| 最大ステップ数 | 2,000 | 整数100〜20,000 |
| 乱数シード | 42 | 整数0〜4,294,967,295 |
| 1歩の長さL | 1 | 画面では1に固定 |
| 偏りb | 0.3 | 0〜1、偏りモデルで使用 |
| 持続確率p | 0.85 | 0〜1、持続モデルで使用 |
| 箱の半幅R | 10 | 整数1〜100、箱モデルで使用 |

さらに、**試行数 × ステップ数 ≤ 20,000,000**を要求する。全座標を毎回更新する`independent`と`gaussian`では、**次元数 × 試行数 × ステップ数 ≤ 20,000,000**も要求する。自己回避成長では次元数≤10、試行数≤512、ステップ数≤1,000、試行数×(ステップ数+1)≤200,000、2×次元数²×試行数×ステップ数≤20,000,000に制限する。

範囲外、整数欄の小数、空欄などは入力エラーとして扱う。コアAPIでは試行数に16〜4,096の整数、`stepLength`に0.001〜1,000の有限な数値を指定できる。設定欄の変更は実行ボタンで反映する。上部の実験例は設定の読み込みと実行をまとめて行う。

乱数にはMulberry32を使う。同じ設定とシードなら同じ計算結果を再現でき、一時停止や再開、1回で進めるステップ数を変えても結果は変わらない。シード0も有効。暗号用途の乱数ではない。

格子歩行は格子上の位置、ガウス歩行は連続値の位置を保持する。座標配列は次元数×試行数に比例し、全時刻の全粒子の全座標は保存しない。集団の統計と代表8粒子の全次元の座標を間引いて保存する。自己回避成長では各粒子の訪問点集合も保持する。端末の性能や描画負荷により実行時間は変わる。

## 図とべき乗フィット

統計曲線にはt=0、対数的に配置した最大約180個の正の時刻、最終時刻を保存する。整数へ丸めて同じ時刻になった点は重複させない。t=0と値が0の点は対数グラフや対数フィットから除外する。

選択範囲の正の有限な点について、以下を重みなし最小二乗法でフィットする。範囲の両端は含む。

```text
y = A t^α
log(y) = log(A) + α log(t)
```

表示する指数αは対数グラフの傾き。フィットには少なくとも3点と異なる時刻が必要。フィット範囲や有限試行の揺らぎによって推定値が変わる。モデルの移行領域を含む場合、1個のαはその区間の実効的な傾きであり、普遍的な指数を測定したとは限らない。R²は対数空間での当てはまりを示す。

同じ試行集団を異なる時刻で観測しているため、点どうしは独立ではない。**信頼区間や推定誤差は計算しない**。R²を指数の信頼度や信頼区間として解釈しない。

「この結果を比較に追加」で計算が完了した実験を最大4件保持し、統計曲線を現在の実験に重ねて表示する。モデル、次元、シード、試行数、時間、保存した時点のフィット範囲を保持する。RMS/MSDを切り替えると、保存時の範囲を使って比較の指数も再計算する。比較はこのページを開いている間のメモリだけに保持し、再読み込みで消える。次元やモデルごとの正規化もそろえて読み取る。

## 高次元の表示

代表軌跡は最初の8試行。各軌跡は原点と最終地点を含めて**最大801点**を保存し、全N座標を保持する。点の間を線で結ぶため、長い実験の細かな曲がりは省略される。

| 表示 | 表現する内容 |
| --- | --- |
| 全次元を3Dへ / `tour` | 全N座標を3本の投影軸へ組み合わせ、3Dとして表示。左右・上下の角度と回転を操作できる |
| 全座標を並べる / `parallel` | 選択時刻の代表8粒子について、各座標軸を横に並べ、同じ粒子の各軸の位置を線で結ぶ平行座標表示。横につなぐ線は移動経路ではない |
| 座標 × 時間 / `heatmap` | 先頭粒子の全座標の保存履歴を色で表示し、選択時刻に縦線を置く。青は負、白は0、橙は正の位置 |
| 2D投影 / `plane` | x₁・x₂の平面。1次元では横軸が時間、縦軸がx₁ |
| 3D投影 / `space` | x₁・x₂・x₃を使った3D表示 |

既定表示は2次元までが平面、3次元が3D、4次元以上が全次元投影。表示時刻のスライダーは代表軌跡の観察用であり、統計曲線の計算範囲や計算済み最新時刻を変更しない。

全次元投影は、球面に配した軸方向をもとに直交化した3本の投影軸を使う。4次元以上の自動回転では座標対のGivens回転でN次元内の投影方向自体を変えるため、単に3Dカメラを回すだけではない。左右・上下の角度は投影後の3Dの向きを操作する。高次元で軸名が密集する場合は一部のラベルを省略するが、座標は省略しない。

**投影図の距離はN次元の実際の距離とは一致しない。** 全次元投影においても、N > 3の空間の全ての位置関係を3次元に保つことはできない。別の表示や角度から見ることで、重なって見える座標の関係を調べる。RMS・MSD・平均距離の計算には、表示方法によらず全N座標を使う。

## CSV

CSVには保存した統計時刻ごとに以下を出力する。行の時刻は等間隔ではない。フィット線と間引く前の全軌跡は含めない。

| 列 | 内容 |
| --- | --- |
| `t` | 経過ステップ数 |
| `rms` | 全試行の二乗平均平方根距離 |
| `msd` | 全試行の平均二乗距離 |
| `mean_distance` | 全試行の平均距離 |
| `theory_rms` | 選択モデルの理論MSDの平方根。時間発展の理論値を設定していないモデルでは空欄 |
| `theory_msd` | 選択モデルの理論MSD。箱・自己回避成長など、時間発展の理論値を設定していないモデルでは空欄 |
| `dims` | 次元数 |
| `walkers` | 試行数 |
| `step_length` | モデルの長さ尺度L |
| `seed` | 乱数シード |
| `model` | モデルの設定キー |
| `bias` / `persistence` / `radius` | 偏り、持続確率、箱の半幅の設定値。使用する値はモデルによる |
| `active_count` | 移動可能な粒子数。自己回避成長の行き止まりで減少 |
| `axis_msd_1` … `axis_msd_N` | 各軸の二乗変位の全試行平均。全軸の和はMSDに等しい |

CSVの理論曲線は、すべてのモデルにL√tを当てはめるものではない。比較に保持した実験は各実験のCSVとは別に扱い、現在の実験を書き出す。

## ファイルと検証

- `index.html` / `styles.css`：ページ、説明、共通ナビゲーション参照、レイアウト。
- `script.js`：入力、実行操作、統計と軌跡の描画、フィット範囲、書き出し。
- `simulation.js`：DOMに依存しないシミュレーション、検証、フィット、CSV生成。ブラウザーでは`RandomWalkCore`、Node.jsでは`module.exports`から利用できる。
- `visualization.js`：高次元投影、平行座標、ヒートマップの描画。ブラウザーでは`RandomWalkView`から利用する。
- `../scripts/random-walk.test.cjs`：次元を変えた拡散則、単位歩幅、全座標と統計の一致、シード再現、分割実行、入力境界、フィット、保存点数、CSVを検証する。
- `../scripts/random-walk-ui.test.cjs`：最小DOMで実際の画面制御とコアを動かし、入力の適用、一時停止・再開、リセット、指標切替、フィット範囲、時刻スライダー、投影、CSV、ホバー表示の状態を検証する。

リポジトリルートで実行する。

```text
node --test scripts/random-walk.test.cjs scripts/random-walk-ui.test.cjs
node --check random-walk-lab/simulation.js
node --check random-walk-lab/visualization.js
node scripts/update-versions.cjs --check
```

ページのバージョンと更新日は[index.html](index.html)のメタデータで管理する。開発時の採番、Hub導線、履歴・一覧の管理は、リポジトリ内の`COMMON_SPEC.md`に従う。
