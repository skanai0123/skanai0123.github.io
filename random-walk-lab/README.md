# Random Walk Lab

初期版 **v1.0.0** / 内容更新日 **2026-09-14**。

1〜100次元の対称なランダムウォークを多数同時に計算し、原点からの距離がステップ数の何乗で増えるかを調べる静的ページ。HTML / CSS / JavaScriptのみで動作し、シミュレーションはブラウザー内で実行する。

## 計算モデルと距離の意味

全試行を原点から開始する。各ステップでN本の座標軸から1本を等確率で選び、その軸の正方向または負方向へ等確率で進む。1歩の長さをLとして、1ステップで進む距離の合計を常にLに固定する。境界、障害物、偏り、試行間の相互作用はない。

時間tは**経過したステップ数**であり、秒ではない。画面では **L = 1** に固定し、距離を歩幅の単位で表示する。N次元位置をx(t)、原点からのユークリッド距離をr(t)として、

```text
r(t) = sqrt(x₁(t)² + … + xₙ(t)²)
MSD(t) = mean(r(t)²)
RMS(t) = sqrt(mean(r(t)²))
平均距離(t) = mean(r(t))
```

`mean`は同じ時刻における全試行の算術平均。RMSと平均距離は異なる量であり、平均距離はRMS以下になる。移動経路に沿った累積の道のりは常に **Lt** である。

独立なステップの平均変位は0、各ステップの二乗長はL²なので、交差項の期待値が消え、

```text
E[x(t)] = 0
E[r(t)²] = t L²
sqrt(E[r(t)²]) = L sqrt(t)
```

が成り立つ。したがって、**RMSの理論指数は1/2、MSDの理論指数は1**。この1歩の長さを固定したモデルでは、総距離の理論RMSに次元数Nの係数は付かない。各座標成分の二乗変位の期待値はtL²/Nである。

理論曲線は無限の試行についての期待値を示す。画面の有限な試行数から求めたRMSやフィット指数は乱数によって変動し、理論線との一致は保証されない。平均位置ベクトルが期待値として0であることも、各試行の原点からの距離が0になることを意味しない。

## 設定と計算量

| 設定 | 既定値 | 範囲 |
| --- | ---: | --- |
| 次元N | 2 | 整数1〜100 |
| 試行数 | 512 | 画面では128・512・2,048・4,096から選択 |
| 最大ステップ数 | 2,000 | 整数100〜20,000 |
| 乱数シード | 42 | 整数0〜4,294,967,295 |
| 1歩の長さL | 1 | 画面では1に固定 |

さらに、**試行数 × ステップ数 ≤ 20,000,000**を要求する。範囲外、整数欄の小数、空欄などは入力エラーとして扱う。コアAPIでは試行数に16〜4,096の整数、`stepLength`に0.001〜1,000の有限な数値を指定できる。

乱数にはMulberry32を使う。同じ設定とシードなら同じ計算結果を再現でき、一時停止や再開、1回で進めるステップ数を変えても結果は変わらない。シード0も有効。暗号用途の乱数ではない。

内部では整数格子座標を保持する。1歩ごとに変わる座標だけを更新し、二乗距離も差分で更新するため、移動計算は次元ごとの全座標再計算を必要としない。座標配列は次元数×試行数に比例する。全時刻の全座標を保存せず、統計と代表軌跡を間引いて保存する。端末の性能や描画負荷により実行時間は変わる。

## 図とべき乗フィット

統計曲線にはt=0、対数的に配置した最大約180個の正の時刻、最終時刻を保存する。整数へ丸めて同じ時刻になった点は重複させない。t=0と値が0の点は対数グラフや対数フィットから除外する。

選択範囲の正の有限な点について、以下を重みなし最小二乗法でフィットする。範囲の両端は含む。

```text
y = A t^α
log(y) = log(A) + α log(t)
```

表示する指数αは対数グラフの傾き。フィットには少なくとも3点と異なる時刻が必要。フィット範囲や有限試行の揺らぎによって推定値が変わる。R²は対数空間での当てはまりを示す。

同じ試行集団を異なる時刻で観測しているため、点どうしは独立ではない。**信頼区間や推定誤差は計算しない**。R²を指数の信頼度や信頼区間として解釈しない。

軌跡図は最初の8試行を代表として表示する。各軌跡は原点と最終地点を含めて**最大801点**を保存し、その間を線で結ぶため、長いシミュレーションでは各ステップの細かな曲がりを省略する。1次元では時間に対する位置x₁を表示する。N≥2の既定表示はx₁・x₂の平面で、N≥3では最初の3座標の固定角度投影に切り替えられる。表示していない座標も、RMS・MSD・平均距離・各軌跡の原点からの距離にはすべて含める。高次元の軌跡の投影距離はN次元の実際の距離とは一致しない。

## CSV

CSVには保存した統計時刻ごとに以下を出力する。行の時刻は等間隔ではない。フィット線と間引く前の全軌跡は含めない。

| 列 | 内容 |
| --- | --- |
| `t` | 経過ステップ数 |
| `rms` | 全試行の二乗平均平方根距離 |
| `msd` | 全試行の平均二乗距離 |
| `mean_distance` | 全試行の平均距離 |
| `theory_rms` | L√t |
| `theory_msd` | L²t |
| `dims` | 次元数 |
| `walkers` | 試行数 |
| `step_length` | 1歩の長さ |
| `seed` | 乱数シード |

## ファイルと検証

- `index.html` / `styles.css`：ページ、説明、共通ナビゲーション参照、レイアウト。
- `script.js`：入力、実行操作、統計と軌跡の描画、フィット範囲、書き出し。
- `simulation.js`：DOMに依存しないシミュレーション、検証、フィット、CSV生成。ブラウザーでは`RandomWalkCore`、Node.jsでは`module.exports`から利用できる。
- `../scripts/random-walk.test.cjs`：次元を変えた拡散則、単位歩幅、全座標と統計の一致、シード再現、分割実行、入力境界、フィット、保存点数、CSVを検証する。
- `../scripts/random-walk-ui.test.cjs`：最小DOMで実際の画面制御とコアを動かし、入力の適用、一時停止・再開、リセット、指標切替、フィット範囲、時刻スライダー、投影、CSV、ホバー表示の状態を検証する。

リポジトリルートで実行する。

```text
node --test scripts/random-walk.test.cjs scripts/random-walk-ui.test.cjs
node --check random-walk-lab/simulation.js
node scripts/update-versions.cjs --check
```

ページのバージョンと更新日は[index.html](index.html)のメタデータで管理する。開発時の採番、Hub導線、履歴・一覧の管理は、リポジトリ内の`COMMON_SPEC.md`に従う。
